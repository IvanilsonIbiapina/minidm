minidm — gerenciador de downloads estilo IDM
=============================================

WINDOWS
-------
1. Extraia TODO o conteúdo do zip para uma pasta (ex.: C:\minidm).
2. Duplo clique em  minidm-gui\minidm-gui.exe  → abre a interface.
3. Se o Windows bloquear (SmartScreen — programa sem assinatura):
   "Mais informações" → "Executar assim". É seguro: é o mesmo código
   publicado no GitHub.
Obs.: fechar a janela some para a BANDEJA do Windows (os downloads
continuam); duplo clique no ícone reabre e o menu "Sair" encerra.

LINUX / macOS
-------------
Extraia o .tar.gz e rode:
   ./minidm-gui/minidm-gui     (interface)
   ./minidm/minidm --help      (terminal)

LINHA DE COMANDO (minidm.exe / minidm)
---------------------------------------
   minidm --help          ajuda
   minidm add <url>       adiciona link(s) à fila
   minidm start           processa a fila
   minidm list            mostra a fila
   minidm deps            o que falta (yt-dlp, ffmpeg...)
   minidm gui             abre a interface (idem duplo clique)

DEPENDÊNCIAS EXTERNAS (licenças próprias)
-----------------------------------------
   yt-dlp   vídeos (YouTube etc.)   https://yt-dlp.org
   ffmpeg   HLS/DASH/conversão      https://ffmpeg.org
O yt-dlp VEM EMBUTIDO no zip (licença Unlicense/GPLv2 — o pacote do
yt-dlp é deles, o código não é copiado): links de página (YouTube,
Instagram...) funcionam sem instalar nada. O ffmpeg continua externo:
sem ele seguem funcionando arquivos diretos e os formatos progressivos
(só faltam conversão mp3, embed e mux vídeo+áudio).
`minidm deps` mostra o que está faltando.

ANDROID
-------
Instale o minidm-android.apk (engine Python embutida). Os arquivos
baixados aparecem em  Download/<categoria>  da pasta pública do
Android (visíveis no app "Downloads" do sistema). Android 10+ não
pede permissão; Android 7-9 pede a permissão de armazenamento na
primeira abertura do app.
Obs.: links de PÁGINA (YouTube, Instagram...) também funcionam no APK
— o yt-dlp vem embutido (sem Termux, sem pip), com runtime JS (quickjs)
e solver EJS embutidos: extração completa do YouTube. Nomes vêm do
Content-Disposition, do link ou do título da página, e download nunca
conclui com 0 bytes.
Saindo do app, a fila continua em SEGUNDO PLANO: um serviço com
notificação de progresso mantém o download vivo (a tela desligada não
corta); o serviço some sozinho quando a fila esvazia.

DOWNLOADS
---------
Por padrão em ~/Downloads/<categoria> (Vídeos, Músicas, Programas,
Documentos, Imagens, Comprimidos). Trocar a pasta base:
   minidm config set download_base D:\Baixadas
